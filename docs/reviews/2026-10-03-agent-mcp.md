# Agent and VS Code MCP follow-up review — 2026-10-03

## Fixed

- Agent resolves the installed `@an5/adapters` package instead of an unavailable sibling source path. Each operation connects and disconnects in `finally`, replacing the shared MSSQL global pool.
- Health queries select the SQL Server, PostgreSQL, MySQL or SQLite dialect. Google Sheets reports unsupported health SQL explicitly.
- Agent and MCP describe live columns through raw adapter queries: SQLite table-valued PRAGMA, or INFORMATION_SCHEMA with primary-key metadata for SQL Server/PostgreSQL/MySQL. MCP no longer calls the nonexistent `table().describe()` method or requires a schema file before live introspection.
- Agent mock execution identifies its adapter and returns the actual row count. Description without metadata or a connection returns an error instead of fabricated columns.
- Schema tools honor the supplied workspace resolver. The reader requires the installed generator's actual module path, preserving provider selection instead of silently falling back.
- Schema-file reads check path boundaries and resolved symlinks, require a regular `.an5` file, and reject other file types.
- SELECT validation accounts for quotes and comments, rejects multiple statements, SELECT INTO, locking/writing keywords, executable comments and ambiguous escaping. It accepts literal semicolons and a trailing comment.
- Existing MCP asynchronous tests are awaited and failures contribute to the exit code. New regressions are part of both package test commands.

## Validation and limits

Both package builds and complete Agent/VS Code test suites pass, including six new regression tests. Actual SQLite tests cover parameter binding, table metadata, health, errors and subsequent operations, using disposable databases. New information-schema/health branches for PostgreSQL, MySQL and SQL Server were not tested against live servers in this follow-up.

SELECT validation is a conservative lexical guard, not a SQL parser or a substitute for database privileges. Functions invoked by SELECT can have side effects; use a database account with read-only privileges for these tools. The helper files are duplicated intentionally because the extension is packaged independently of Agent/adapters.

This follow-up covers query, connection, schema access and MCP test execution. Generation/migration command dispatch and the legacy Agent metadata text parser still require separate review.

The extension 1.1.0 follow-up adds the connection UI and reviews command dispatch and language-specific MCP generation; see [extension UI review](2026-10-03-extension-ui.md).
