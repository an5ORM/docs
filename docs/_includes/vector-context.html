Examples for your stack

{% include docs-context-form.html %} {% if provider == 'postgresql' %}

Enable pgvector and store embeddings in a vector column with the same dimension as the query. Native search requires a compatible column; otherwise the runtime falls back to scanning rows in memory.

{% elsif provider == 'sqlserver' %}

Native search requires SQL Server 2025 VECTOR_DISTANCE and compatible embeddings. Earlier versions use the in-memory fallback.

{% elsif provider == 'nbase' %}

NBase vector integration is documented for the TypeScript runtime. The examples below use an NBase-only adapter; no relational table is required.

{% else %}

This provider has no native vector search in AN5. Where supported, the runtime loads matching rows and ranks their embeddings in memory. Limit table size and filter candidates early.
