PostgreSQL note: Enable pgvector and store embeddings in a vector column with the same dimension as the query. Native search requires a compatible column; otherwise the runtime falls back to scanning rows in memory.

{% elsif provider == 'sqlserver' %}

SQL Server note: Native search requires SQL Server 2025 VECTOR_DISTANCE and compatible embeddings. Earlier versions use the in-memory fallback.

{% elsif provider == 'nbase' %}

NBase note: NBase vector integration is documented for the TypeScript runtime. The examples below use an NBase-only adapter; no relational table is required.

{% elsif provider == 'sqlite' %}

SQLite note: A VECTOR(n) column stores a BLOB of little-endian float32 and the search is ranked inside the database — by sqlite-vec when it loads, otherwise by the runtime's own an5_vec_* functions or json_each. No extension is required. Write and read a plain array of numbers; see Vector Search.
